# Getting help

## Where to look first

- [`README.md`](./README.md): what the platform is, the design decisions (D1 to D11), configuration and
  the production setup.
- [`docs/database-setup.md`](./docs/database-setup.md): preparing PostgreSQL.
- [`docs/architecture.md`](./docs/architecture.md) and [`docs/security-model.md`](./docs/security-model.md).
- [`CONTRIBUTING.md`](./CONTRIBUTING.md): building and testing from source.
- [c15t's own documentation](https://c15t.com/docs/self-host) for the consent banner and the c15t backend.

## Asking a question or reporting a bug

Open an issue at <https://github.com/Axiumine/c15t/issues/new/choose>. Use the bug report form for
something that is broken (include the version or commit, your Node.js version, and the log lines with
secrets removed) and the feature request form for an idea. Please search the existing issues first.

## Security problems

Do not use public issues. Follow [`SECURITY.md`](./SECURITY.md) and report privately.

## What to expect

This is a volunteer-run project with no support contract and no guaranteed response time for general
questions. We usually look at new issues within a week. Commercial support is not offered.
